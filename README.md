# 🚀 CareerPath AI

### Personalized Career Roadmaps for Students

CareerPath AI is a web-based career planning application built for **Hack Devengers 2.0**.

Many students know the career they want but don't know:

* What skills they are missing
* What they should learn first
* Which projects they should build
* How to structure their weekly learning

CareerPath AI addresses this by turning a student's current profile and career goal into a personalized learning roadmap.

---

## 🎯 Problem

Students often face information overload when planning their careers.

A student may know they want to become an **AI Engineer, Software Engineer, Data Analyst, or Web Developer**, but finding the right sequence of skills, projects, and learning goals can be difficult.

CareerPath AI provides a structured starting point based on the student's individual situation.

---

## 💡 Solution

The application collects:

* Education
* Current technical skills
* Target career
* Experience level
* Available study time

It then generates a personalized career pathway containing:

* 🔎 Skill-gap analysis
* 🗺️ Learning roadmap
* 📅 Weekly study plan
* 💡 Project recommendations
* 🚀 Recommended next step

---

## ✨ Key Features

### 🎓 Personalized Assessment

Students provide their education, skills, experience level, career goal, and available study time.

### 🔎 Skill Gap Analysis

The application identifies important skills that may be needed for the selected career.

### 🗺️ Structured Roadmap

Skills are organized into a logical learning sequence so students know what to focus on next.

### 📅 Weekly Study Plan

The roadmap is converted into a simple weekly learning routine.

### 💡 Project Recommendations

Students receive practical project ideas related to their target career.

### 📱 Responsive Interface

The application is designed to work across desktop and smaller screens.

## ▶️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/careerpath-ai.git
```

### 2. Open the project

```bash
cd careerpath-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

### 5. Open the application

Visit:

```text
http://localhost:3000
```

## 🔐 Environment Variables

If using optional external AI services in future versions, API keys should be stored in a `.env` file.

Never upload API keys or `.env` files to GitHub.

The `.gitignore` file excludes:

```text

.env
```
